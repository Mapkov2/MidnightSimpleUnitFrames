## **MSUF 5.0 is out**

**This is a big one.**  
The menu got a major next-level upgrade. Same MSUF feeling, but cleaner, faster and much easier to use.

Unit Frames now also have the same preview workflow as Group Frames. There is better Edit Mode access, Undo / Redo, window snapping and full localization.

**Dev Note:**  
This release is mostly about making configuration finally feel good and fixing a lot of annoying edge cases around previews, portraits, auras, range checks and menu behavior.
