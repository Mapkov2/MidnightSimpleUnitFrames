MSUF setup guide

Unit frames for WoW Forever

Customize the player, target, focus, pet, party and raid frames with Midnight Simple Unit Frames (MSUF). The stable download includes support for the Forever client.

Download on CurseForge Download on Wago Manual ZIP on GitHub

Install MSUF in WoW Forever

  1. Select WoW Forever in your addon manager, then install Midnight Simple Unit Frames. For the manual download, look for the Forever flavor under the CurseForge files.
  2. Launch WoW Forever and enable MSUF in the AddOns list. Open the configuration with /msuf.
  3. Set up the player and target frames first. Then use MSUF Edit Mode to position party and raid frames and preview their layout before joining a group.

Try a Forever profile

Mapko published Forever – Blizzard Modern on Wago. Copy the import string, open Profiles in MSUF, and paste it into Import. Export your current profile first if you want a backup. Use Edit Mode to adjust the result for your screen.

Which frames work in Forever?

Forever supports player, target, focus, pet, pet target, party and raid layouts. MSUF offers dedicated arena layouts on Midnight, TBC Anniversary and Mists Classic. Use the regular Raid layout in Forever.

Install from the ZIP

Download the packaged ZIP under Assets on GitHub. Extract both MidnightSimpleUnitFrames and MidnightSimpleUnitFrames_Options directly into Interface/AddOns inside the WoW client you play. Restart the game, enable MSUF in the AddOns list, and type /msuf.
